# Changelog

## Driftwave 1.0 Beta 1 (2026-11-18)

The first release on the main **Driftwave** channel.

- **A new look:**
  - a Driftwave logo and app icon (a sun setting over drifting waves);
  - the player on a floating card;
  - minimise, maximise and close centred on the title row;
  - smooth animations everywhere (pages, cards, the player), never flashing.
- **17 homage themes:** Windows 3.1, 95, XP, Vista, 7 and 11; classic Mac OS, Mac OS X, today's Mac and the iPhone; DOS; a rainy Tokyo night; Atari, Nokia, SNES, Genesis and Winamp. Realistic ones use real photographs and real-looking rain. Each has easter eggs.
- **Your own background:** a GIF or picture from a file or GIPHY, behind any theme. Every GIF is checked frame by frame, and anything that flashes is refused.
- **Lighter:**
  - effects rest when Driftwave isn't the active window;
  - animated themes use about a third of the CPU they did;
  - memory is given back when the app is minimised or in the tray;
  - several memory leaks are fixed.
- **Updates:** Settings > Updates installs new releases with one click. A playing station carries on. Betas are offered to the main channel, and the final 1.0 will count as newer.
- **Everything from the nightly builds so far:**
  - Discover, search and a library of stations, with import and export.
  - Song titles in time with the audio, in the app, the Windows media overlay and on media keys.
  - Recording: each song saved as its own MP3 or M4A, copied exactly.
  - Mini player, notification-area icon, background playback, notifications.
  - Nine built-in themes and your own, with calm effects (no flashing).
- **Coming from the early private "Shortwave" build?** Install.ps1 removes it, and Driftwave copies your library and settings on its first launch.
